# Beamforming for Star-borne Reflector: Digital Beamforming

A Novel Digital Beam-Forming Concept for Spaceborne Reflector SAR Systems
The model used to generate data to prove the results is from Bu-Chin Wang's book:  
Digital Signal Processing Techniques and Applications in Radar Image Processing
Algorithm
The process is divided into two main stages: data synthesis and processing.
In the synthesis stage, the goal is to generate raw data that will be received by all channels along the SAR of a linear antenna array and a parabolic reflector dish. Firstly, a symmetric linear frequency modulated signal is generated to model the initial pulse transmitted by the radar, starting with the imaging of the ground. Based on the structure of the radar and the reflector, the actual transmission way of the signal on the ground is standardized. This gain pattern is not isotropic (meaning spherical), so it is necessary to adjust the amplitude of the signal according to its physical projection on the ground. The paper refers to this as "single complex channel mode". Then, an artificial environment for point reflectors is constructed.
In the processing stage, the received signals are compressed to select important channels. Then, conjugate field matching is applied to create an in-focus image.
